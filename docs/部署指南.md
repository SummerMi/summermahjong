# 部署指南：广东麻将（推倒胡）后端服务

> 面向新手，从"本机跑起来"到"公网能访问"。每一步都给了可直接复制的命令。
> 本文命令在 **Windows 11 + Python 3.12.3 + Docker 27.3.1 + Compose v2.30.3** 上实测过；
> 云厂商的界面、价格、免费额度会变，涉及钱和额度的都标了「以官网为准」，不编造链接。

| 部署方式 | 适合场景 | 耗时 | 成本 |
|---|---|---|---|
| A. 本机直接跑 | 改代码、写简历时自测 | 2 分钟 | 0 |
| B. Docker 跑 | 演示、验证镜像，最接近线上 | 5 分钟 | 0 |
| C. 云服务器 + Nginx + HTTPS | 投简历放公网、面试官点开就能看 | 1–2 小时 | 约 10–30 元/月 |
| D. 免费平台（Render / HF Spaces） | 零成本体验"公网部署"，但会休眠 | 30 分钟 | 0 |

**结论先说**：给国内投简历用，选 **C（腾讯云轻量 / 阿里云 ECS 学生机）**；D 只用来练手和应急。



CMD（推荐，最简单）：

```bat

set PYTHONUTF8=1
.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

PowerShell：


Git Bash（本仓库日常用的就是 bash）：

```bash

PYTHONUTF8=1 .venv/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

乱码的另一种修法（只想在控制台里看清，不想动环境变量）：

> 说明：`chcp 65001` 改的是控制台代码页，只在"直接看控制台"时有效；只要涉及重定向/管道/被别的程序捕获，**必须用 `PYTHONUTF8=1`**（UTF-8 模式对标准输出、标准错误、文件默认编码都生效）。两个一起用最稳。


## 3. 公网部署 A：腾讯云轻量应用服务器 / 阿里云 ECS（推荐）

> 下面以 **Ubuntu 22.04/24.04 LTS** 为例，两家云厂商的界面不同但命令完全一样。
> 大陆节点的服务器，对外提供网站服务**需要 ICP 备案**（80/443 端口）；没备案的话有两个选择：买**香港/新加坡等境外节点**（无需备案，国内访问稍慢但可用），或先用非标端口（体验差，不推荐写进简历）。

### 3.1 买机器 + 开端口

| 步骤 | 做什么 | 说明 |
|---|---|---|
| 1 | 买 **2 核 2G / 2 核 4G** 轻量应用服务器，系统 Ubuntu 22.04 LTS | 学生机/新人活动价约 10–30 元/月，常规价约 60–100 元/月，**以官网为准** |
| 2 | 控制台「防火墙 / 安全组」放行 **22、80、443** | 不要放行 8000：对外只暴露 Nginx，后端只监听本机 |
| 3 | 记下公网 IP，`ssh root@公网IP` 登录 | 首次登录建议先改密码/配密钥 |

### 3.2 装 Docker

```bash
# 方式一：官方一键脚本（以官方文档为准）
curl -fsSL https://get.docker.com | sh

# 方式二：走 apt 官方源（更可控，步骤以 Docker 官方文档为准）
# apt update && apt install -y docker.io docker-compose-v2

docker --version
docker compose version
systemctl enable docker        # 开机自启，容器带 restart: unless-stopped 就会跟着起来
```

### 3.3 把代码弄上去

```bash
# 方式一：仓库已推到 GitHub（推荐，后面更新方便）
apt install -y git
git clone https://github.com/<你的账号>/<仓库名>.git ~/gd-mahjong
cd ~/gd-mahjong

# 方式二：从本机 scp 上传（仓库还没公开时用）
# 在 Windows Git Bash 里执行（注意排除 .venv，别把几百 MB 传上去）：
# rsync -av --exclude '.venv' --exclude '__pycache__' --exclude '.git' \
#   /c/Users/SumMi/Documents/agent-learning/fastapi/ root@公网IP:~/gd-mahjong/
```

### 3.4 配生产环境变量并起服务

不要用 compose 里写死的 `CORS_ORIGINS: "*"`，在生产覆盖掉。在服务器上创建 `.env`：

```bash
cd ~/gd-mahjong
cat > .env <<'EOF'
APP_NAME=广东麻将（推倒胡）后端服务
VERSION=0.1.0
CORS_ORIGINS=https://你的域名.com
MAX_GAMES=100
GAME_TTL_SECONDS=7200
EOF
```

注意一个容易踩的坑：**compose 不会自动把项目目录的 `.env` 注入容器**。它只在做 `${VAR}` 变量替换时读那个文件；容器的环境变量只来自两处，且 `environment:` 的优先级高于 `env_file:`。所以要在生产改值，二选一：

- 直接改 `docker-compose.yml` 里 `environment:` 的那几行（最直接），或
- 把 `environment:` 换成 `env_file:`：

```yaml
services:
  api:
    env_file: .env          # 覆盖掉写死的 environment，或者直接删掉 environment 段
```

然后起服务：

```bash
docker compose up -d --build
docker ps --filter name=gd-mahjong-api     # 等 15~35 秒，状态变 (healthy)（首次探测受 30s 间隔 + 10s 启动宽限影响）
curl -s http://127.0.0.1:8000/healthz      # 服务器本机先自测
```

### 3.5 Nginx 反向代理（80 → 8000）

```bash
apt install -y nginx
cat > /etc/nginx/sites-available/gd-mahjong <<'EOF'
server {
    listen 80;
    server_name 你的域名.com;

    # 上传体积限制：本服务都是小 JSON，给 1m 足够
    client_max_body_size 1m;

    location / {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Host              $host;
        proxy_set_header X-Real-IP         $remote_addr;
        proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        # CORS 预检要能透传到后端
        proxy_set_header Origin            $http_origin;
    }
}
EOF
ln -sf /etc/nginx/sites-available/gd-mahjong /etc/nginx/sites-enabled/gd-mahjong
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx
```

DNS：在域名服务商加一条 **A 记录**，`你的域名.com → 公网 IP`，等生效（几分钟到几小时）。验证：

```bash
curl -s http://你的域名.com/healthz
```

### 3.6 HTTPS（Let's Encrypt，免费）

```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d 你的域名.com        # 按提示选「重定向 HTTP 到 HTTPS」
certbot renew --dry-run               # 验证自动续期（证书 90 天，certbot 自带定时任务）
```

证书免费、自动续期；**域名要花钱**（见第 7 节），备案免费但需要时间（1–20 个工作日，以管局为准）。

### 3.7 开机自启 / 日志 / 更新

```bash
# 开机自启：docker 已 enable，容器有 restart: unless-stopped，服务器重启后会自动拉起
systemctl status docker
docker ps --filter name=gd-mahjong-api

# 服务日志（应用日志全在容器 stdout）
docker compose logs -f --tail 100
journalctl -u docker -n 100 --no-pager

# Nginx 日志
tail -f /var/log/nginx/access.log
tail -f /var/log/nginx/error.log

# 更新流程（改完代码后）
cd ~/gd-mahjong
git pull                                     # 或 rsync 覆盖
docker compose up -d --build                 # 重新构建并滚动重启
docker ps --filter name=gd-mahjong-api       # 确认新容器 healthy
```

### 3.8 一条龙验收清单

```bash
curl -s https://你的域名.com/            # 简介
curl -s https://你的域名.com/healthz     # status=ok
curl -s https://你的域名.com/api/v1/mahjong/tiles | head -c 100
curl -s -o /dev/null -w "%{http_code}\n" -X POST https://你的域名.com/api/v1/calc/divide \
  -H "Content-Type: application/json" -d '{"a":1,"b":0}'    # 期望 400
docker exec gd-mahjong-api id                                # uid=10001
# 浏览器打开 https://你的域名.com/docs
```

## 4. 公网部署 B：免费/低门槛平台（Render / HuggingFace Spaces）

> 定位：**零成本练手 + 简历上有个公网 URL 兜底**。国内面试官点开大概率要等冷启动，别把它当主推。

### 4.1 Render（Docker 部署，最接近真实流程）

| 项 | 实际情况（免费 Web Service 档，以官网为准） |
|---|---|
| 部署方式 | 连 GitHub 仓库，选 Docker，自动读 `Dockerfile` 构建 |
| 端口 | 平台会注入 `$PORT`，服务必须监听它；本项目 Dockerfile 固定 8000，需要在 Render 的 **Docker Command** 里覆盖：`uvicorn app.main:app --host 0.0.0.0 --port $PORT` |
| 健康检查 | 在设置里填 `/healthz`（本服务已提供） |
| 休眠 | 免费实例一段时间无请求会休眠，再次访问有 **30–60 秒冷启动**（以官网为准） |
| 外网访问 | 免费给 `https://xxx.onrender.com`，自带 HTTPS |
| 国内访问 | 一般能打开，但慢；冷启动期间可能超时 |

### 4.2 HuggingFace Spaces（Docker SDK）

| 项 | 实际情况（免费 CPU 档，以官网为准） |
|---|---|
| 部署方式 | 新建 Docker 类型 Space，把代码推到 Space 自己的 git 仓库 |
| 前置条件 | Space 根目录**必须有 `README.md`**（YAML 头里写 `sdk: docker`、`app_port: 8000`）；本仓库已有 README，但上 Space 前要在开头补一段 YAML front matter（不要覆盖现有项目介绍） |
| 端口 | 默认要求 7860；通过在 README 的 YAML 里声明 `app_port: 8000` 改成本服务的端口（以官方文档为准） |
| 休眠 | 免费 Space 长时间无访问会休眠，访问时冷启动；**国内访问不稳定** |
| 外网访问 | 给 `https://<用户名>-<space名>.hf.space`，自带 HTTPS |

### 4.3 为什么国内投简历还是建议自建轻量服务器

| 对比项 | 免费平台（Render / HF） | 自建轻量服务器（C 方案） |
|---|---|---|
| 冷启动 | 30–60s，面试官可能直接关页面 | 无，常驻进程 |
| 国内访问速度 | 慢，偶发打不开 | 大陆节点快；香港机也够用 |
| 自定义域名 + HTTPS | 免费域名难绑，绑定流程受限 | 自有域名 + certbot 一键 HTTPS |
| 环境可控 | 平台限制端口/存储，日志有限 | root 权限，想看什么日志都行 |
| 面试价值 | "我部署过" | "我配了 Nginx 反代 + 证书自动续期 + 容器非 root"（**这句能聊 5 分钟**） |
| 成本 | 0 | 约 10–30 元/月（学生机），比一杯奶茶贵不了多少 |

> 结论：**B 用来练手和应急，C 用来写进简历。** 面试官问"你这个项目上线了吗"，能说出域名 + HTTPS + 开机自启 + 日志位置，比"部署在 Render 上"有分量得多。

## 5. 环境变量表

定义在 `app/core/config.py`（`Settings`，pydantic-settings，大小写不敏感，支持 `.env` 文件）。

| 变量 | 默认值 | 作用 | 生产建议 |
|---|---|---|---|
| `APP_NAME` | `广东麻将（推倒胡）后端服务` | 服务名，出现在 `/`、`/docs` 标题、启动日志 | 可保留中文 |
| `VERSION` | `0.1.0` | 版本号，`/healthz` 和 OpenAPI 都会返回 | 每次发布递增，方便确认部署生效 |
| `CORS_ORIGINS` | `*` | 允许跨域来源，**逗号分隔**（不是 JSON 数组） | 改成 `https://你的域名.com`，多个用逗号隔开 |
| `MAX_GAMES` | `100` | 内存里最多保留多少局，超限淘汰最久未访问的 | 按内存估算，100 局约几 MB，别盲目调大 |
| `GAME_TTL_SECONDS` | `7200` | 对局闲置多少秒后被清理（2 小时） | 演示可调小（如 600）方便看清理日志 |

### 5.1 修改后怎么生效

配置**只在进程启动时读取一次，没有热加载**，改完必须重启：

| 场景 | 改哪里 | 生效命令 | 验证 |
|---|---|---|---|
| 本机 CMD | `set X=Y` | 重启 uvicorn | `curl /healthz` 看 `version` 变了 |
| 本机用 `.env` | 仓库根目录新建 `.env`（当前仓库没有，`Settings` 会自动读） | 重启 uvicorn | 同上 |
| Docker run | `-e KEY=VALUE` | `docker run` 重新起 | `docker exec gd-mahjong-api env \| grep KEY` |
| Docker Compose | `docker-compose.yml` 的 `environment:` 或 `env_file:` | `docker compose up -d`（有变化会重建） | `docker compose config` 看解析结果 |
| 云服务器 | 服务器上的 `.env` 或 compose | `docker compose up -d --build` | `curl https://域名/healthz` |

`.env` 示例（放仓库根目录，`.dockerignore` 已经排除它，不会打进镜像）：

```dotenv
APP_NAME=广东麻将（推倒胡）后端服务
VERSION=0.1.0
CORS_ORIGINS=http://localhost:5173,https://你的域名.com
MAX_GAMES=100
GAME_TTL_SECONDS=7200
```

> 验证配置到底生效没有，最快的办法是改 `VERSION` 后重启，然后 `curl /healthz`——返回新版本号就说明读到了。

## 6. 排错清单

| # | 现象 | 最可能原因 | 处理命令 / 动作 |
|---|---|---|---|
| 1 | 启动报 `[Errno 10048] error while attempting to bind on address ('127.0.0.1', 8000)` | 8000 端口被占（上次的 uvicorn 没退干净） | `netstat -ano \| findstr :8000` 找 PID → `taskkill /F /PID <PID>`；或换端口 `--port 8001` |
| 2 | 前端报 `No 'Access-Control-Allow-Origin' header` | `CORS_ORIGINS` 没包含前端地址，或网关没透传 `Origin` | 检查 `CORS_ORIGINS` 是否是完整来源（带 `https://`，末尾不要 `/`）；反代加 `proxy_set_header Origin $http_origin;`；改完重启服务 |
| 3 | 浏览器报 `Credentials is not supported if the CORS header ... is '*'` | `allow_credentials=True` 和 `*` 同时用，浏览器规范禁止 | 本项目固定 `allow_credentials=False`；要带 cookie 就必须写具体域名（同源部署可完全不用 CORS） |
| 4 | 容器 `(healthy)` 但外面访问不通 | ① `-p` 没映射 ② 云安全组没开 ③ Nginx 没起 ④ 后端只监听 127.0.0.1 | `docker port gd-mahjong-api` → 云控制台放行 80/443 → `systemctl status nginx` → `curl 127.0.0.1:8000/healthz`、`curl 公网IP/healthz` 逐段定位 |
| 5 | 容器一直 `(unhealthy)` | `/healthz` 打不通或启动失败 | `docker logs gd-mahjong-api --tail 50`；`docker inspect --format '{{json .State.Health}}' gd-mahjong-api` 看最近一次探针输出 |
| 6 | 中文日志乱码（`��������`） | Windows 控制台/重定向用 cp936 编码 | `set PYTHONUTF8=1`（根治，管道和重定向都生效）；只看控制台可 `chcp 65001`；PowerShell 用 `$env:PYTHONUTF8="1"` |
| 7 | `pip install` 特别慢或超时 | 默认走国外源 | 换国内镜像（以镜像站官网为准）：`pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple`；uv 用 `UV_INDEX_URL` 环境变量或 `--index-url` |
| 8 | `docker build` 卡在 pip 安装 / 拉基础镜像失败 | 国内拉 Docker Hub 慢 | 给 Docker Desktop 配镜像加速器（以厂商文档为准），或重试；`docker build` 时先确认 `docker pull python:3.12-slim` 能通 |
| 9 | 云服务器 `curl 公网IP` 超时 | 安全组/防火墙没放行 | 腾讯云轻量「防火墙」放行 80/443；阿里云「安全组」入方向放行；服务器内 `ufw status`、`iptables -L -n` |
| 10 | HTTPS 申请失败（certbot） | 域名没解析到本机 / 80 端口被占 / 备案未下 | `dig +short 你的域名.com` 确认是公网 IP；`nginx -t`、`systemctl status nginx`；大陆节点需先备案 |
| 11 | `/api/v1/games/{id}` 返回 404 `GAME_NOT_FOUND` | 多进程/多副本导致状态分裂，或容器重启后内存清空 | 本项目**只能单进程跑**（内存 store）；核对 `uvicorn --workers` 是否为 1；容器重启会丢所有对局，这是设计限制 |
| 12 | 页面 404 但 `/healthz` 正常 | 路径写错（比如少了 `/api/v1`） | 打开 `/docs` 对照 9 条路径：`/`、`/healthz`、`/api/v1/calc/{op}`、`/api/v1/mahjong/{tiles,win-check,tenpai}`、`/api/v1/games`、`/api/v1/games/{id}`、`/api/v1/games/{id}/discard` |
| 13 | 500 `INTERNAL_ERROR` | 代码抛了未捕获异常 | `docker compose logs --tail 100` 找堆栈；响应体故意只给通用文案（不泄漏内部细节），真相在日志里 |

## 7. 成本估算

> 价格为 2026 年参考区间，活动价随时变，**以云厂商官网为准**；域名和备案按国内常规流程估算。

| 项目 | 费用 | 说明 |
|---|---|---|
| 云服务器（2 核 2G，学生机/新人活动） | **约 10–30 元/月** | 腾讯云轻量 / 阿里云 ECS 的学生或新人套餐；常规价约 60–100 元/月 |
| 云服务器（2 核 4G） | 约 30–60 元/月（活动） | 跑这个服务 2G 绰绰有余，主要看你要不要顺便学别的 |
| 域名 | `.com` 首年约 50–80 元；`.cn` 约 30 元；续费原价 | 便宜的一年一续，**以注册商官网为准** |
| HTTPS 证书 | **0 元** | Let's Encrypt，90 天自动续期（certbot 定时任务） |
| ICP 备案 | **0 元** | 大陆服务器必做，需 1–20 个工作日；境外/香港节点不需要 |
| 对象存储/CDN | 0 元 | 本服务纯 JSON、无静态资源，不需要 |
| 免费平台（Render / HF Spaces） | 0 元 | 代价是休眠 + 冷启动 + 国内访问慢 |

**最低配方案**：一台 2 核 2G 学生机（约 10–30 元/月）+ 一个便宜域名 + Let's Encrypt 免费证书 = **首年约 150–400 元**，就能在简历上写"公网可访问，HTTPS，Docker 部署"。
