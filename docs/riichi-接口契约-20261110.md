# riichi 接口契约（冻结 v1 · 2026-11-10）

> **这份文件是并行的地基。** 任何人改契约必须先找 Lead 同意，并在 `docs/adr/` 记一条 ADR、把版本号 +1。
> 契约版本：**v1**；对应仓库：`summermahjong/riichi`。

## 0. 变更规则

1. 契约文件由 **Lead 独占写权限**；其他人只能读。
2. 改契约 = 改接口/事件/协议/错误码，**必须**：ADR + 版本号 + 通知所有在跑的切片。
3. 兼容期内允许「新增字段」，不允许「改名/删字段」。

## 1. 包边界与依赖方向

```
internal/tile     牌、牌山（无依赖）
internal/rules    判胡拆解、向听、役种、符、点数（只依赖 tile）
internal/game     对局状态机、Observation、事件（依赖 tile + rules）
internal/agent    智能体接口与实现（依赖 game，禁止被 game 依赖）
internal/store    事件/快照持久化（依赖 game 的事件类型，不依赖 transport）
internal/transport HTTP/WS（依赖 game + store）
internal/eval     评测（依赖 game + agent）
cmd/*             组装
```

**铁律**：依赖只能向下（`transport → game → rules → tile`），禁止反向；`agent` 只读 `game`，禁止写状态。

### 2.2 Action / Event

```go
type Action struct {
	Kind    ActionKind
	Seat    Seat
	Tile    tile.Tile     // 打牌/和了牌/被副露的牌
	Consumed []tile.Tile  // 副露消耗的手牌（吃：2 张；碰：2 张；杠：3 张）
	Options  map[string]any // 预留（如立直宣言牌、杠的种类）
}

type Event struct {
	Seq     uint64         `json:"seq"`
	Kind    EventKind      `json:"kind"`
	Seat    Seat           `json:"seat"`
	Payload json.RawMessage `json:"payload,omitempty"`
}
```

事件类型（**冻结全集**，未实现的可先不产生）：

| EventKind | payload 关键字段 |
|---|---|
| `round_start` | `round_wind, kyoku, honba, dealer, scores` |
| `draw` | `tile, wall_remaining` |
| `discard` | `tile, tsumogiri(bool), riichi_declared(bool)` |
| `chi` / `pon` / `kan` | `tile, consumed[], kan_type` |
| `riichi` | `tile, ippatsu_eligible(bool)` |
| `dora_reveal` | `indicator, dora[], is_ura(bool)` |
| `tsumo` / `ron` | `winning_tile, yaku[], han, fu, points, score_deltas[]` |
| `ryuukyoku` | `reason(nagashi/kyuushu/haitei), tenpai_seats[], score_deltas[]` |
| `round_end` | `dealer_repeat(bool), honba, riichi_sticks` |
| `game_end` | `final_scores[]` |
| `agent_thought` | `seat, agent, candidates[], chosen, elapsed_ms` |
| `error` | `code, message` |

### 2.3 State

```go
type State struct {
	Rules Ruleset
	Seed  int64

	RoundWind Wind; Kyoku int; Honba int; RiichiSticks int
	Dealer Seat; Turn Seat; Phase Phase

	Wall     *tile.Wall
	Hands    [4][]tile.Tile
	Melds    [4][]Meld
	Discards [4][]tile.Tile
	Scores   [4]int
	Drawn    *tile.Tile
	Riichi   [4]bool
	Furiten  [4]bool

	Seq    uint64
	Events []Event
}

type Meld struct {
	Kind  string // chi / pon / kan_daiminkan / kan_shouminkan / kan_ankan
	Tiles []tile.Tile
	From  Seat
}
```

### 2.4 契约函数（S1 冻结签名，S5 实现）

```go
func New(seed int64, rules Ruleset) (*State, error)
func LegalActions(s *State, seat Seat) []Action   // 该座位当前可做的全部动作
func Apply(s *State, a Action) error              // 校验 + 推进 + 追加事件
func Replay(seed int64, rules Ruleset, actions []Action) (*State, error)
```

### 2.5 Observation（Agent 唯一输入）

```go
type Observation struct {
	Seat          Seat
	Hand          []tile.Tile
	Drawn         *tile.Tile
	Melds         [4][]Meld
	Discards      [4][]tile.Tile
	DoraIndicators []tile.Tile
	Scores        [4]int
	Riichi        [4]bool
	WallRemaining int
	RoundWind     Wind
	Kyoku, Honba, RiichiSticks int
	LegalActions  []Action   // 只能从这里面选
}
```

**安全约束**：`Observation` 不得包含其他三家手牌、牌山顺序、裏宝牌指示牌。构造函数：

```go
func Observe(s *State, seat Seat) Observation
```

**验收测试（必须有）**：构造一手牌，`Observe` 结果里搜不到对手手牌的牌张信息（用「对手手牌含 1m×4 且观察者手里没有 1m」这类用例断言）。

## 4. Agent 接口（S8 实现）

```go
package agent

type Agent interface {
	Name() string
	Decide(ctx context.Context, obs game.Observation) (game.Action, error)
}
```

**约定**：
- 返回的 `Action` 必须在 `obs.LegalActions` 内，否则服务端丢弃并回退到第一个合法动作（记录 `error` 事件）。
- 默认决策上限 **500ms**（可配），超时回退启发式首选。
- 允许实现内部有状态（记忆），但**不得**依赖任何未在 `Observation` 中出现的信息。

## 5. Store 接口（S7 实现）

```go
type Store interface {
	CreateGame(ctx context.Context, meta GameMeta) error
	AppendEvents(ctx context.Context, gameID string, events []game.Event) error

	SaveSnapshot(ctx context.Context, gameID string, atSeq uint64, snapshot []byte) error
	LoadSnapshot(ctx context.Context, gameID string) (snapshot []byte, atSeq uint64, err error)

```

实现：`store/memory`（默认）、`store/sql`（MySQL 事件表）、`store/redis`（事件流）。三者行为必须一致（同一组接口测试跑三遍）。

## 6. 传输协议（S6 实现）

### 6.1 HTTP

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/v1/games` | 建局：`{seed, ruleset, agents:[...]}`，需 JWT |
| GET | `/api/v1/games/{id}` | 当前状态（裁剪到请求座位） |
| GET | `/api/v1/games/{id}/replay` | 全量事件（回放用） |
| GET | `/api/v1/games/{id}/metrics` | 耗时/决策次数等 |

### 6.2 WebSocket `/api/v1/ws/games/{id}?seat=&token=`

客户端 → 服务端：

```json
{"type":"action","seq":43,"action_id":"uuid","action":{"kind":"discard","tile":"2m"}}
{"type":"resume","last_seq":41}
{"type":"ping","ts":123}
```

服务端 → 客户端：

```json
{"type":"event","seq":42,"kind":"discard","seat":1,"payload":{...}}
{"type":"resumed","from_seq":42,"to_seq":50}
{"type":"pong","ts":123}
{"type":"error","code":"ILLEGAL_ACTION","message":"..."}
```

**幂等**：同一 `action_id` 重复提交只执行一次；`seq` 不匹配返回 `STALE_SEQ`。

## 7. 错误与幂等约定

| 错误码 | 含义 |
|---|---|
| `ILLEGAL_ACTION` | 动作不在合法集合内 |
| `STALE_SEQ` | 客户端 seq 落后（返回需要 resume 的提示） |
| `SEAT_MISMATCH` | 令牌与座位不符 |
| `GAME_NOT_FOUND` | 局不存在 |
| `INTERNAL` | 兜底 |

Go 侧统一用 `errors.Is` 判定的哨兵错误：`ErrIllegalAction`、`ErrSeatMismatch`、`ErrGameNotFound`。
